# Interactive Resume Builder

A professional and responsive web-based Resume Builder developed as part of **Veda Technology Web Development – Task 29**.

The application allows users to enter personal information, education, experience, and skills while viewing a live formatted resume preview in real time.

## 📌 Project Overview

The Interactive Resume Builder is a frontend web application designed to simplify resume creation.

Users can enter their information through a structured form and instantly see the changes reflected in a professional resume preview.

The project focuses on:

- Two-way data binding patterns
- Live preview rendering
- Dynamic form sections
- Responsive web design
- Print-friendly resume formatting

---

## 🎯 Objective

The main objective of this project is to build an interactive resume creation interface using HTML5, CSS3, and JavaScript.

The application demonstrates how user input can be captured and dynamically rendered into a formatted resume layout.

---

## ✨ Features

### Personal Information
Users can enter:

- Full Name
- Professional Title
- Email
- Phone
- Location
- LinkedIn
- GitHub

### Professional Summary

Users can add a short professional summary that updates automatically in the resume preview.

### Education

- Add multiple education entries
- Remove education entries
- Degree / Course
- Institution
- Year
- Score / CGPA

### Experience

- Add multiple experience entries
- Remove experience entries
- Job Role
- Company
- Duration
- Description

### Skills

Users can enter multiple skills separated by commas.

### Live Preview

The resume preview updates whenever the user changes the form fields.

### Responsive Design

The interface works across:

- Desktop
- Laptop
- Tablet
- Mobile devices

### Print / PDF

The resume includes a print-friendly layout.

Users can use the browser's:

**Print → Save as PDF**

option to generate a PDF version of the resume.

### Reset

The Clear button allows users to remove all entered information and start again.
